First public release of GTAIV-FastGPS for GTA IV Complete Edition 1.2.0.59.

- Faster native GPS rerouting and motion-aware missed-turn detection.
- Direction-aware pathfinding with adaptive forward-route preferences and native fallback.
- Configurable INI and optional diagnostic log, both beside the ASI.

Requires a compatible 32-bit ASI loader. Extract the ZIP into the game or loader plugin directory, remove any older FastGPS ASI, and restart. See the repository for configuration and technical notes. Other GTA IV versions are unsupported.
